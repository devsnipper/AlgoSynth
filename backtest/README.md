# backtest/ : the only place research happens

The live bot runs from the repository root (`main.py` and the files next to it). It trades real orders on the
account, so **nothing outside `backtest/` is changed from research work**. A guard in `.claude/` (local, not
committed) blocks edits outside this folder, git commands that change the working tree, and any attempt to start or
stop the bot.

| Folder | Content | Status |
|---|---|---|
| `backtesting_1/` | Replay of the live EMA bot on 70 days of Boom/Crash. Report and strategy plan. | Finished |
| `rsi_test/` | Does RSI predict spikes or mark better zones? | Finished, no |
| `smc/` | SMC research: shared core, one folder per setup, runner, tests. | In progress |

## Environment

```
python -m venv backtest/.venv
backtest/.venv/Scripts/python.exe -m pip install -r backtest/requirements.txt
```

`requirements.lock.txt` records the exact versions used for the results.

## Notes

- `backtesting_1/` imports the live `strategy.py` and `config.py` read-only, to replay the exact EMA rules. It never
  writes to them. `smc/` imports nothing from the live code.
- Price files (`**/data/*.csv`) are git-ignored and regenerated by the download tools. The download tools only read
  from the MetaTrader terminal.
