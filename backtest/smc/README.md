# SMC research (backtest zone)

Everything here is research code. **It never imports from, or writes to, the live bot** (`main.py`, `config.py`,
`strategy.py`, `trader.py`, `notifier.py`, `reporter.py`, `.env`, `logs/`). Nothing in `backtest/` may reuse one of
those file names.

## Layout

```
run.py            single entry point (today: `test`)
core/             shared, setup-agnostic code
  constants.py      data blocks A/B/C, split date, timeframes
  data.py           load candles and symbol settings
  primitives.py     swings, structure breaks, FVG, spike clipping, sweep + shift detection (no look-ahead)
  engine.py         limit-order trade simulator on M5 candles
setups/           (next step) one folder per setup: setup.py, NOTES.md, test_setup.py, reports/
tests/            tests for the shared code
tools/            download_history.py (read-only MT5 download), diagnose_setups.py, reference_orders.py
docs/             SMC_STRATEGY.md, SETUP_LIST.md (frozen list and rules), BUILD_PLAN.md
data/             price files (git-ignored, regenerated by tools/download_history.py)
```

## Run

```
backtest/.venv/Scripts/python.exe backtest/smc/run.py test
```

The backtest environment is separate from the bot's: `backtest/.venv` (see `backtest/requirements.txt`).

## Rules

- Data blocks: **A** tuning, **B** final verdict looked at once, **C** older months. See `docs/SETUP_LIST.md`.
- No look-ahead: a value at candle `t` uses candles up to `t` only. `tests/test_primitives.py` checks this on real data.
- Results are in R (profit divided by planned risk).
